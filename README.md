# Кадр / Kadr Studio

Русскоязычная браузерная студия для генерации изображений и видео через OpenRouter. Слева — промпт, модель, референсы и оценка стоимости. Справа — лента работ. Готовый кадр можно скачать или одним нажатием использовать в следующей генерации.

Приложение написано на HTML, CSS и JavaScript. Все файлы готовы к запуску. Для работы достаточно современного браузера, доступа в интернет и собственного API-ключа OpenRouter с доступом к нужной модели. Для локального запуска ниже используется Python 3.

## Быстрый запуск

1. В GitHub нажмите **Code → Download ZIP** и распакуйте архив. Если пользуетесь Git, выполните команды ниже.

   ```sh
   git clone https://github.com/tkuzyuminskaya1988-hue/kadr-studio.git
   cd kadr-studio
   ```

2. Откройте терминал в папке, где лежат `index.html` и этот README. В Windows можно открыть папку в Проводнике, ввести `powershell` в адресную строку и нажать Enter.

   **Windows (PowerShell)**

   ```powershell
   python -m http.server 8000 --bind 127.0.0.1
   ```

   **macOS или Linux**

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

3. Оставьте терминал открытым и перейдите в браузере по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000/). Чтобы остановить сервер, нажмите **Ctrl+C** в терминале. При следующем запуске используйте тот же адрес и тот же браузер, чтобы увидеть прежнюю историю.

Если Windows не распознаёт `python`, попробуйте `py -3 -m http.server 8000 --bind 127.0.0.1`. Если Python ещё не установлен, скачайте [Python 3](https://www.python.org/downloads/). Если порт занят, замените `8000` на `8001` и в команде, и в адресе браузера. Другой порт откроет отдельную историю.

## Первая генерация

1. Создайте ключ в OpenRouter. В студии нажмите **API-ключ**, вставьте ключ и нажмите **Подключить**. Баланс или доступный лимит появится вверху. [Управление ключами OpenRouter](https://openrouter.ai/settings/keys) · [Кредиты OpenRouter](https://openrouter.ai/settings/credits)
2. Выберите **Изображение** или **Видео**, затем модель. Для первого изображения можно взять **Примеры промптов** или написать свой, например «Туманное утро на набережной, мягкий боковой свет, общий план».
3. Для изображения задайте размер и качество. Для видео выберите разрешение, длительность, формат кадра и звук. Над кнопкой запуска появится примерная стоимость в долларах.
4. Нажмите **Сгенерировать**. В ленте сразу появится карточка с индикатором. Можно редактировать форму и запускать следующую работу. Каждый запуск использует промпт, референсы и параметры, выбранные на момент нажатия.
5. После завершения на карточке появятся результат и сумма, которую вернул OpenRouter. Кнопка **Скачать** сохраняет оригинальный файл, **В референсы** добавляет его в редактор. Выбор ролика автоматически переключает редактор в режим видео.

## Референсы и промпты

Перетащите файлы в область **Референсы** или нажмите на неё, чтобы открыть выбор файлов. Рядом с каждым вложением появятся миниатюра или кнопка прослушивания и короткое имя. Изображения получают имена `img1`, `img2`, видео — `video1`, аудио — `audio1`. Нумерация отдельная для каждого типа и начинается в порядке добавления.

Например, можно приложить два фото и написать в видеопромпте:

> Персонаж из @img1 идёт по улице из @img2. Камера плавно движется рядом.

Введите `@`, чтобы выбрать вложение из списка. Работают и обозначения без собачки, например `img1`. Карточки референсов можно перетаскивать или перемещать стрелками ↑ и ↓, когда выбрана ручка перемещения. При смене порядка ссылки в промпте обновляются. После удаления файла его упоминание помечается как удалённое. Замените его или уберите перед запуском.

В режиме изображения используются JPG, PNG и WebP. В режиме видео доступны также BMP, MP4, MOV, MP3 и WAV. Ограничения на размер, размеры кадра и длительность зависят от модели. При нарушении лимита редактор покажет сообщение рядом со вложениями.

**Как передаются файлы.** Для генерации изображений студия передаёт фото непосредственно в OpenRouter в составе запроса. Для генерации видео при запуске студия загружает приложенные референсы в TempFile и передаёт модели открытые HTTPS-ссылки. Студия запрашивает срок хранения 6 часов. В течение срока действия ссылку может открыть тот, кто её получил.

## История, ключ и расходы

| Что | Где хранится и как работает |
| --- | --- |
| Готовые изображения, видео, промпты и стоимость | В IndexedDB браузера для адреса, по которому открыта студия. История переживает перезагрузку и обычное закрытие вкладки. |
| API-ключ | В `sessionStorage` текущей вкладки. Приложение отправляет ключ только на API OpenRouter. Ключ вводится в интерфейсе, сборка и файл конфигурации для него не нужны. |
| Незавершённое изображение | Ответ с изображением принимает открытая вкладка. Дождитесь результата перед закрытием или перезагрузкой. |
| Незавершённое видео | После принятия задачи OpenRouter её номер сохраняется в сессии вкладки. При перезагрузке студия восстанавливает проверку. Закрытие вкладки может завершить эту сессию. |
| Удалённая работа | **Удалить** с подтверждением убирает файл и промпт из локальной истории. Для учёта расходов остаются служебный идентификатор и известная сумма. Удаление выполняющегося запроса из ленты не отменяет его у провайдера. |

Перед запуском отображается **оценка**, а после завершения — **фактическое списание**, если OpenRouter его сообщил. Для параллельных запросов студия учитывает оценки активных задач, когда баланс или лимит ключа доступен. Реальные расходы также можно проверить в [OpenRouter Activity](https://openrouter.ai/activity).

При переносе папки на другой компьютер переносится приложение. Важные результаты скачайте из ленты отдельно. Другой браузер, другой адрес сайта или очистка данных сайта дадут отдельную или пустую историю.

## Размещение на своём сайте

Подойдёт HTTPS-хостинг статических файлов. Скопируйте `index.html`, `style.css`, три файла JavaScript и папку `assets/` в один каталог. Относительные пути позволяют разместить студию и в подпапке. Пользователь вводит собственный ключ после открытия сайта. Публиковать ключ рядом с исходниками не требуется.

## Если что-то пошло не так

| Что видно | Что проверить |
| --- | --- |
| В браузере список файлов или ошибка 404 | Запустите команду из каталога с `index.html`. Проверьте адрес и порт. |
| OpenRouter возвращает 401 или 402 | Для 401 переподключите ключ. Для 402 проверьте баланс аккаунта и доступный лимит ключа. |
| Ошибка 429 | Провайдер ограничил частоту запросов. Подождите перед следующим запуском. |
| TempFile не подтвердил файл | Проверьте доступ к TempFile и ограничения выбранной модели. Попробуйте заново приложить файл. |
| Связь прервалась во время отправки | Сначала проверьте Activity в OpenRouter. Провайдер мог принять задачу и списать средства до потери связи. |
| История пуста после запуска | Откройте тот же адрес, порт и профиль браузера, где создавались работы. Если браузеру не хватило места, скачайте результат из карточки до закрытия вкладки. |

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| `index.html`, `style.css` | Интерфейс студии и адаптивная раскладка. |
| `app.js` | Редактор, модели и тарифы, параллельные задачи, карточки ленты и управление референсами. |
| `api.js` | Запросы в OpenRouter, загрузка в TempFile, опрос видеозадач и операции с IndexedDB. |
| `mentions.js` | Подсветка упоминаний, подсказки по `@` и перенумерация референсов в тексте. |
| `assets/` | Знак студии и иллюстрации для примеров промптов. |
